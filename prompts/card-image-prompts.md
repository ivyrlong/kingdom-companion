# Game Card Image Prompts

Prompts for generating the games-page card art. Each is self-contained — paste
and run as-is.

**How the set stays cohesive:** the style + palette + exclude block is byte-identical
in every prompt; only the first sentence (scene + lead colour) changes. Reuse the
**same seed / style reference** across all 16, varying only that first sentence.

**Palette (Faithful Companion — from `src/app/globals.css`):**
coral `#FF8269` · sky `#4ABDE8` · violet `#9474EF` · golden `#F3B840` ·
peach `#FFA56B` · cream base `#FAF8F6` · ink `#3C3F4A`

**Content rules baked in:** no crosses (use an upright stake or lamb/sheep for
sacrifice themes), no halos, no holiday imagery, original characters only (never
Caleb & Sophia or any branded likeness), Jehovah/Jesus never depicted
(silhouettes only). Hangman deliberately has **no gallows/noose**.

**Recommended output:** ≥1024px long edge, landscape ~2:1 (matches the card's
image area), then let the UI scale it down. Upload via **Admin → Game Images**.
