# Character Bible

The 32 modern-people stickers, named and pinned. Use this file whenever
you want a specific character to appear anywhere else on the site — a
Watchtower story panel, an encyclopedia illustration, a memory-match
card, a Meeting Live moment. Copy the character's **frozen identity
string** verbatim into your new prompt so the person stays recognisably
themselves across every use.

The four family clusters (Miller, Bell, Reyes, Kim) are a suggested
organising fiction so children can imagine whole families together. You
are not required to keep them as families — kids playing the paradise
builder will mix and match freely.

## How to reuse a character elsewhere

Once per character, generate the sticker (from `sticker-prompts.md`).
The resulting PNG **is** that character's canonical portrait — save the
final file as the sticker filename shown below and keep a copy in a
tidy folder so you can find it again.

For any new use of the character (a story scene, a game card, etc.):

1. Open your image tool.
2. **Upload the canonical portrait as a reference image** (ChatGPT's
   image gen, Midjourney `--cref`, Ideogram / Recraft / Flux Kontext all
   support this — each is called "character reference" or similar).
3. Paste the frozen identity string below, then add the new scene
   (`… kneeling by a stream to fill a jug, sunny afternoon`, etc.).
4. Keep the same shared style + palette block from the other prompt
   files so the visual language matches.

If the image tool drifts (different face, wrong hair), turn up the
character-reference weight, or regenerate — do not paste the drifted
version back in as the new reference or the character will slowly
morph away from herself.

## Every entry follows this shape

```
### Name (role, family)
- Filename: sticker-people-<variant>-<role>.png
- Frozen identity: <copy-paste string>
- Suggested nicknames / short forms: <optional>
```

# Later, once the app uses characters programmatically

When we want the site to know these characters (link a sticker on a
paradise page to Amara's canonical portrait, or embed Josiah in a
Watchtower story image the admin uploads), a small Prisma model earns
its keep:

```prisma
model Character {
  id              String   @id @default(cuid())
  slug            String   @unique   // "emma-miller"
  name            String              // "Emma Miller"
  role            String              // "mother" | "grandfather" | …
  variant         String              // "blonde" | "black" | …
  family          String?             // "Miller"
  identityPrompt  String              // the frozen string, verbatim
  portraitUrl     String?             // path to canonical portrait PNG
  createdAt       DateTime @default(now())
  updatedAt       DateTime @updatedAt
}
```

Stickers, story scenes, encyclopedia entries, and paradise saves can
all foreign-key against `Character.slug` — a character rename ripples
everywhere for free, and admins can browse "everything Emma appears in"
at one URL.

Not needed until we start using characters outside the sticker set.
When that day comes, ping me and I'll add the model + a seed migration
from this file.
