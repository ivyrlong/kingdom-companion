# Paradise Builder — Scene Prompts

Prompts for the "book pages" — the opaque background scenes children
sticker onto. Same visual language as `sticker-prompts.md` so the whole
sticker library and every scene read as one cohesive storybook: same
style + palette block byte-identical in every prompt, only the first
sentence changes.

## Output spec (paste into your image tool, apply to every scene prompt)

- **PNG or JPG, OPAQUE background** (NOT transparent — the scene IS the
  background).
- **Wide 2:1 landscape**, 2048×1024 px works well (also 1920×960 or
  1536×768 fine; keep 2:1 for consistent framing).
- Composition rule: **mostly empty**. Horizon around lower third, sky
  above, open grass / sand / water below with plenty of clear space
  for kids to place stickers.
- **No people, no animals, no cottages, no wells, no benches, no
  potted plants, no bouquets, no fruit-tree-in-foreground** — every
  one of those is a sticker. If the scene ships with a giraffe in it,
  the giraffe sticker becomes redundant.
- Same shared palette + soft golden light + flat-vector style as the
  stickers, so a sticker child placed on a scene doesn't clash.
- **No shadow constraints** (unlike stickers) — the scene has its own
  lighting.
- **Filename**: `scene-<slug>.png` → drop in `public/uploads/scenes/`.

## Content rules baked into every scene prompt

- No crosses, halos, or holiday imagery.
- No branded characters (Caleb & Sophia, Disney, etc.).
- No depictions of Jehovah or Jesus.
- No boats, vehicles, or man-made structures.
- Wildflowers as ground texture / distant trees as scenery are fine —
  they read as landscape, not as sticker-competitors.

## What to do with these

1. Paste each prompt into your image tool.
2. Save as the filename shown above.
3. Drop them in `public/uploads/scenes/`.
4. When you have 3–4 done, tell me — the game shell will let kids
   pick a scene from a small tray, then sticker onto it. You can keep
   adding scenes later without any code change.
